IoT Based Infant Incubator Monitoring System

Arduino-based IoT system to monitor temperature, humidity, pulse rate, and gas levels of an infant incubator. Includes real-time LCD display and cloud monitoring using ThingSpeak.

Real-Time Intrusion Detection Using GNU Radio and USRP

Bistatic RF intrusion detector built with a pair of USRP software-defined radios: one continuously transmits a sinusoidal carrier while the other monitors received signal power and its statistical variation, flagging an intrusion when both deviate significantly from a learned baseline.

Includes: Tx/Rx GNU Radio Companion flowgraphs and an embedded Python detection block.
